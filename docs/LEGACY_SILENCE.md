# 经典禁言版 v3.1.0

## 简单说

这个版本把“群聊总结”和“群聊禁言”放在同一个插件里。

它可以照常接收和保存群消息，再把日报发给管理员私聊；同时也可以阻止机器人往指定群里发送任何内容。

[下载经典禁言版 v3.1.0](https://github.com/artinsteinbrecher-lab/MaiBot-private-daily-analysis/releases/download/v3.1.0/khiqwq_daily_analysis-v3.1.0-legacy-silence.zip) ·
[查看 v3.1.0 Release](https://github.com/artinsteinbrecher-lab/MaiBot-private-daily-analysis/releases/tag/v3.1.0)

## 什么时候选它

只有在下面两点都成立时才建议使用：

1. 你确实需要某些群里的机器人完全不说话；
2. 你明确希望禁言功能和总结功能放在同一个插件里。

如果你更在意总结效果、完整度和可读性，请使用 v3.6.0。v3.1.0 是为了保留旧用法，不是当前效果最好的版本。

## 安装步骤

1. 先备份现有插件目录和 `config.toml`。
2. 如果已经安装 v3.6.0，先停用并移走它。两个版本的插件 ID 相同，不能同时加载。
3. 解压 `khiqwq_daily_analysis-v3.1.0-legacy-silence.zip`。
4. 把解压得到的唯一插件文件夹放进 MaiBot 插件目录。
5. 在 WebUI 中先配置来源群、管理员和日报接收账号，暂时不要开启禁言。
6. 管理员私聊发送 `/summary 群号 今天`，确认日报能正常生成。
7. 最后打开 `[silence]`，先测试一个群；确认管理员私聊仍然正常后，再增加其他群。

## 禁言会挡住什么

开启后，目标群中的以下内容都会被阻止：

- MaiBot 普通回复；
- @ 机器人后的回复；
- 群内命令回复；
- 其他插件发往该群的消息；
- 日报插件自己可能产生的群消息。

管理员私聊和没有加入禁言名单的群不受影响。禁言群必须同时位于日报来源群名单中。

## 切换版本要注意

- v3.1.0 和 v3.6.0 的配置结构不同，不要直接用一个版本的完整配置覆盖另一个版本。
- 切换前保留备份，一次只加载一个版本。
- 从 v3.1.0 升级到 v3.6.0 后，内置 `[silence]` 不再生效；需要禁言时改用独立的“QQ 群绝对静默守卫”。
- 不要为了试用而在重要群直接开启禁言，先用测试群确认边界。
