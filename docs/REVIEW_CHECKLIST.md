# 本地候选审阅清单

## 共同核心

- [ ] 两版 `plugin.py`、`core/` 和 `templates/` 文件逐字节一致。
- [ ] 默认配置为“完整覆盖 + 完整详情”。
- [ ] 不包含 MBTI、压抑指数、情绪评级、趣味称号、金句排行或活跃轨迹模板。
- [ ] 事实、结论和待办必须绑定真实消息 ID；编排不得新增事实；复核不得新增声明。
- [ ] 图片失败会回退事实型文本，失败分片会显示“部分完成”和时间范围。

## 普通插件版

- [ ] 目录中没有 `extras/`。
- [ ] README 明确只安装插件，不修改 MaiBot。
- [ ] 四个内部流程统一跟随 `replyer`。
- [ ] 配置示例不出现供应商、URL、API Key 或模型 ID。

## 多模型增强改包版

- [ ] 插件核心与普通版完全相同。
- [ ] `--check` 完全只读。
- [ ] `--apply` 只接受 `MODEL_CONFIG_VERSION = "1.17.6"` 的干净基线。
- [ ] 应用前备份四个目标文件，第二次应用幂等。
- [ ] 未知版本和部分安装状态拒绝修改。
- [ ] 回滚前校验安装后哈希，避免覆盖后续人工修改。
- [ ] 任一高级任务留空时由 MaiBot 真实回退 `replyer`。
- [ ] 模型分配文档区分官方型号与供应商别名，不保存凭据。

## 发布卫生

- [ ] 不含 `.git/`、`__pycache__/`、`*.pyc` 或真实 `config.toml`。
- [ ] 不含 SSH 密码、私钥、API Key、Token 或服务器配置导出。
- [ ] 两版单元测试和 Python 编译检查通过。
- [ ] `SHA256SUMS.txt` 与 `FILE_MANIFEST.txt` 已重新生成。
- [ ] 用户审阅后才决定是否提交、打包或上传 GitHub。
