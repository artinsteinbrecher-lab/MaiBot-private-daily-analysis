# 安全说明

## 支持范围

安全修复仅针对当前主分支和最新发布版本。报告问题时请附上 MaiBot 版本、插件版本、
部署方式和已经脱敏的错误日志。

## 请勿公开提交的内容

- QQ 登录凭据、NapCat Token
- MaiBot WebUI Token
- 模型 API Key
- SSH 密码或私钥
- 含真实私聊、群聊内容的完整日志或截图
- 未经当事人同意的 QQ 号、群号和成员信息

提交 Issue 前，请将账号、群号、Token、请求头、聊天文本和服务器地址替换为占位符。

## 数据流

插件从 MaiBot 读取白名单群的已存消息，通过配置的 MaiBot 模型任务生成摘要，
再通过 MaiBot 发送到指定管理员私聊。启用 `inject_memory` 时，摘要还可能被追加到
MaiBot 会话上下文。

插件自身不读取模型 API Key、NapCat Token、WebUI Token 或服务器登录凭据。

## 绝对静默

绝对静默是高影响功能：它会在发送前拦截目标群的所有出站消息，包括其他插件输出。
启用前应确认群号无误，并保留可用的管理员私聊通道。它不会阻止群消息接收、存储和总结。

## 漏洞报告

请优先通过仓库的私密漏洞报告功能联系维护者。若仓库未启用该功能，请创建不含利用细节
和敏感数据的 Issue，请求维护者提供私下沟通方式。
